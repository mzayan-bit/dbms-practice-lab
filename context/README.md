# Context & Course Material Directory

Use this directory to store your course slides, lecture notes, syllabus, textbook chapters, and reference materials.

---

## How It Works

1. **Place Materials Here**:
   Drop your lecture PDFs, PowerPoint presentations (`.pptx`), markdown notes, or text files directly in this directory (or inside a subfolder like `context/lectures/` or `context/slides/`).

2. **Start a Course Session**:
   Tell Antigravity:
   > *"Practice Chapter 3 slides"* or *"I just added my lecture notes on Relational Algebra & SQL joins in context/"*

3. **Tutor Adaptation**:
   Antigravity will:
   - Read and analyze the uploaded course material.
   - Extract the core concepts, definitions, and specific course notation.
   - Formulate custom, step-by-step SQL exercises mapped to your course syllabus.

---

## Privacy & Git Protection

> [!NOTE]
> All files in `context/` matching common document and slide formats (`.pdf`, `.pptx`, `.ppt`, `.docx`, `.epub`, etc.) or subdirectories like `context/materials/` are automatically excluded in `.gitignore`.
>
> Your private lecture slides and copyrighted university materials will **never** be committed or pushed to your public GitHub repository.
